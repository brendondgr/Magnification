# Plan Setup

When configuring the planning skill, please answer the following questions to tailor plan output:

1. **Plan Granularity:** Should plans be brief executive outlines, detailed engineering checklists, or full phase-by-phase implementation plans?
2. **Validation Workflow:** What verification steps should plans prefer (unit tests, integration tests, manual QA, screenshots, linting, type checks, CI)?
3. **Git Workflow:** Should each completed phase include commit-only instructions, GitHub push instructions, pull request instructions, or no Git workflow guidance?
4. **Audience:** Are plans primarily for solo implementation, team handoff, stakeholder review, or agentic coding workflows?

*(AI Note: Adjust `plan/planner.md` guidance based on the user's answers when generating project-specific planning rules.)*
