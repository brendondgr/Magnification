# Profile README Template

This goes in a public repo named exactly the user's GitHub username (e.g. `github.com/username/username`), in `README.md` at the repo root. GitHub auto-renders it as a banner at the top of the profile page.

Target: readable in under 30 seconds. Two or three sections, each scannable in under 10 seconds.

```markdown
### [One-line bio — what they build, not a job title]
[e.g. "Building federated multi-agent knowledge graph systems | PhD student, Computational Science"]

**Currently:** [one line on the active project — signals momentum]

**Core stack:** [3–5 technologies, not an exhaustive list]

---

#### Featured
- **[Repo name](link)** — [one real sentence: what it does / result, not a restated title]
- **[Repo name](link)** — [same]
- **[Repo name](link)** — [same]

---

[One outbound link: personal site, or wherever someone can understand the
person fastest. Pick one deliberately — five scattered links dilute signal.]
```

## What to leave out

- Long tool-badge walls ("I know 15 languages") — signals breadth without depth
- Animated GIF carousels / visitor counters — distraction, not signal
- Generic filler bio lines ("passionate developer," "lifelong learner")
- More than 6 pinned/featured repos — GitHub's own pin limit is 6; don't exceed that logic even in a featured list

## What earns its place

- A specific, technical one-liner per featured repo (not just the repo name)
- A single stats widget if used, not several redundant ones
- One clear, current "what I'm building now" line — this is the highest-signal single sentence on the page, since it gives a concrete reason for someone to reach out
