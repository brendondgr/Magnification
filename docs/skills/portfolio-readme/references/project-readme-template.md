## Notes on tone

- Avoid "Built with ❤️" filler and emoji walls — recruiters flagged these as noise, not charm.
- Don't list every technology ever touched. 3–5 architecturally significant ones beats a stack of 15 badges.
- If the project was a tutorial/course follow-along, either be upfront about that and describe what was extended beyond the tutorial, or don't pin it — reviewers can tell, and the gap between "clone" and "extended with X" is exactly what they're checking for.
